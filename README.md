# 九州クエスト

九州の道の駅146駅を探す、iPhone向けの静的Webアプリです。GitHub Pagesで公開します。

## 使い方

最初のメール入力は端末内の照合です。本人確認やアクセス制限ではありません。スタンプも端末内に保存され、別端末とは同期しません。

## データと写真

道の駅情報と写真の出典は、各駅の詳細にリンクした国土交通省九州地方整備局のページです。情報を検索用に整理・加工しています。雑誌の誌面画像はこの公開リポジトリおよび公開サイトに含めていません。

## 開発

pnpm install → pnpm check → pnpm build

ビルド結果は docs/ に作成され、GitHub Pagesは main ブランチの /docs を公開します。
